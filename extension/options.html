告诉采集器，内容在哪里。

选择器使用 CSS 语法。默认适配示例页面；真实 iWork 页面需要按实际结构配置。

采集范围

仅在你点击采集时读取当前标签页，不会在所有站点后台注入。先展开正文与评论、显示附件，再执行采集。

编号只接受明确的数字字段或问题 URL 路径 / 查询参数，不会使用标题中的年份或其他数字。编号字段优先读取 data-bug-id，也可读取 value 或纯数字文本。

附件需要下载链接与原始文件名；可使用 href / data-url 和 download / data-name。图片读取 src，文件名读取 data-name / alt。临时授权下载链接只传给本地助手，扩展不会将其保存在设置中。

受登录失效、分页、跨域下载或页面结构变化影响的证据会列为缺口。不会写入问题、发送消息或修改附件。
